## 🌟 Overview

**Zennx Downloader** is a universal, zero-cloud, client-side media downloader for Android, Windows Desktop, and CLI. It extracts watermark-free videos, high-resolution original photos, lossless FLAC & MP3 audio tracks, and carousels directly from 16+ platforms without routing personal data through remote intermediary servers.

This repository (`elskyx/About-Zennx-Downloader`) hosts the official introducing landing website deployed on **GitHub Pages**:
👉 **[https://elskyx.github.io/About-Zennx-Downloader/](https://elskyx.github.io/About-Zennx-Downloader/)**

---

## 📱 Features Showcased on the Site

- **Interactive Live Simulator**: Experience how Zennx parses and downloads from TikTok, Instagram, Spotify, YouTube, and Pinterest right in your browser.
- **Cross-Platform Matrix**:
  - 🤖 **Android**: Native share-sheet integration, quick save overlay, Material dynamic theming.
  - 🪟 **Windows Desktop (Tauri v2 + Rust)**: Native sub-15MB footprint, drag-and-drop links, batch multi-threading.
  - ⚡ **CLI (Node.js / npm)**: Headless terminal utility (`npm i -g @elskyx/zennx`), pipeable JSON outputs for scripts.
- **Platform Support**: TikTok, Instagram, YouTube, Spotify, Pinterest, X/Twitter, Facebook, Threads, SoundCloud, Bilibili, Reddit, Douyin, XiaoHongShu, Bandcamp, Pixiv, and TeraBox.
- **Mori-Inspired Design**: Built with warm linen tones, fluid canvas animations, and zero-dependency vanilla web standards.

## 💻 Local Preview

Run locally with any static web server:

```bash
# Clone the repository
git clone https://github.com/elskyx/About-Zennx-Downloader.git
cd About-Zennx-Downloader

# Preview via Python
python -m http.server 3000

# Or preview via npx serve
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
